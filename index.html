01

Getting started

Before you begin

Overdrive is an Online Store 2.0 theme for supplement, nutrition and repeat-purchase wellness stores. You need a Shopify store, permission to manage themes, and approved product content.

Important

Replace demonstration copy with accurate product information. Only publish health claims, certifications, guarantees and customer reviews that you can substantiate.

Recommended preparation

  • Product titles, descriptions, prices, inventory and high-resolution images
  • Collections for the categories customers should browse
  • Shipping, refund, privacy and terms policies in Shopify Admin
  • Verified ingredients, usage directions and certification documents
  • Navigation menus and store contact details
02

Installation

Install without disturbing your live store

  1. 1
    Open Themes

    In Shopify Admin, go to Online Store → Themes.

  2. 2
    Upload the ZIP

    Select Add theme → Upload zip file, then choose the Overdrive release file.

  3. 3
    Customize unpublished

    Open the theme editor and configure the theme while it remains unpublished.

  4. 4
    Preview and test

    Test products, variants, cart, search, customer accounts and localization.

  5. 5
    Publish when ready

    Duplicate your current live theme first, then publish Overdrive.

04

Theme editor

Configure the global design system

Open Theme settings to control appearance, colors, typography, layout width, buttons, borders, shadows and motion. Light and dark appearances use the same content while changing the storefront color system.

Brand

Upload your logo and favicon. If no logo is selected, the shop name is used.

Colors

Set background, surface, text, muted, border and accent colors with accessible contrast.

Typography

Choose Shopify-hosted heading and body fonts. No external font script is required.

Motion

Use subtle motion or disable it. Reduced-motion customer preferences are respected.

05

Header and navigation

Build paths customers understand

Create menus under Content → Menus, then select them in the Header and Footer sections. Nested menu items become dropdown navigation. The header also includes predictive search, the Shopify account component, localization, appearance control and cart access.

Categories in Shopify

Store categories are normally managed as Collections. Creating a collection does not automatically add it to navigation; add its link to your selected menu.

Option selectors update availability, media and variant-specific pricing.

Selling plans

Native selling-plan allocations display one-time and recurring purchase choices where configured.

App blocks

07

Product pages

Configure a complete product story

The main product section supports rich media, zoom, variants, swatches, comparison and unit pricing, selling plans, quantity controls, dynamic checkout, pickup availability, sticky add-to-cart and app blocks.

Recommended block order

  1. Vendor, title, rating and price
  2. Short product description
  3. Variant and purchase-option controls
  4. Quantity and purchase buttons
  5. Verified policies, pickup and expandable details

Use complementary and related-product sections below the main product section. Recently viewed products are stored in the customer’s browser.

08

Discovery

Collections, filters and search

Create and manage collections in Products → Collections. Overdrive renders Shopify’s native storefront filters, active filters, sorting and pagination on collection and search pages.

Configure filters

  1. Install or open Shopify Search & Discovery.
  2. Select the filters customers need, such as availability, price, product type, vendor or variant options.
  3. Use consistent product data so filters remain useful.
09

Cart and discounts

Keep totals transparent

The cart page and drawer display item discounts, automatic order discounts, selling-plan details, original totals and savings supplied by Shopify. Configure discount codes and automatic discounts in Shopify Admin.

Why there is no promo-code input

Theme code cannot reliably apply cart-level discount codes without app-like API functionality. Customers can enter eligible codes during Shopify checkout, while automatic discounts appear directly in the cart.

Markets

Languages, countries and Arabic RTL

English, French, German, Spanish, Italian and Arabic locale files are bundled. Publish and translate store resources through Shopify Markets and Translate & Adapt. Country and language selectors appear when multiple options are available.

Arabic automatically uses right-to-left layout direction. Always review merchant-entered content, third-party app blocks and uploaded graphics in RTL before publishing.

12

Inclusive storefronts

Accessibility responsibilities

Overdrive includes keyboard-operable controls, visible focus states, semantic landmarks, reduced-motion support and accessible dialog behavior. Merchants remain responsible for meaningful image alt text, logical headings, descriptive links, captions and adequate color contrast after customization.

FAQ

Common questions

Can I switch between light and dark appearances?

Yes. Configure both color systems in Theme settings. Customers can use the header appearance control when it is enabled.

Where are product categories managed?

Use Shopify Collections for storefront categories, then add those collection links to your menus and homepage sections.

Does Overdrive include a subscription backend?

No. The theme supports Shopify selling plans and displays allocations created by a compatible subscription solution.

Can I add reviews or a product quiz?

Yes. Install a compatible app and place its app block in an available section. Overdrive does not require a particular paid app.

Why do demo images remain after installation?

Bundled demonstration assets provide a polished starting point. Replace them using the section image pickers and adjust focal points in the editor.

What is included in theme support?

Support covers theme setup questions, documented features and reproducible theme defects. Store strategy, custom development, third-party app configuration and product claims are outside standard theme support.
